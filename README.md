# Инструмент для визуализации выравнивания аминокислотных последовательностей

## Описание

Это веб-приложение для визуализации выравнивания аминокислотных последовательностей с цветовой схемой, соответствующей физико-химическим свойствам аминокислот. Инструмент позволяет наглядно сравнивать две последовательности и выделять их различия.

## Функциональность

- Ввод двух аминокислотных последовательностей
- Валидация ввода (только допустимые символы аминокислот и одинаковая длина)
- Визуализация выравнивания с цветовой схемой
- Адаптивный дизайн (работает на устройствах с шириной экрана от 320px)
- Копирование выделенной последовательности в буфер обмена
- Поддержка поиска по странице (cmd+F / ctrl+F)

## Цветовая схема аминокислот

- **Цистеин (C)** - #FFEA00
- **Гидрофобные (A, I, L, M, F, W, Y, V, P)** - #67E4A6
- **Глицин (G)** - #C4C4C4
- **Отрицательно заряженные (D, E)** - #FC9CAC
- **Положительно заряженные (K, R)** - #8B99FF
- **Полярные незаряженные (S, T, H, Q, N)** - #80BFFF

## Технологии

- TypeScript
- React
- Material UI
- React Hook Form с Yup для валидации

## Установка и запуск

1. Клонировать репозиторий:
```
git clone https://github.com/sergey38202/BIOCAD-test.git
cd biocad-test
```

2. Установить зависимости:
```
npm install
```

3. Запустить приложение в режиме разработки:
```
npm start
```
Откройте [http://localhost:3000](http://localhost:3000) для просмотра в браузере.

4. Сборка для продакшена:
```
npm run build
```

5. Деплой на GitHub Pages:
```
npm run deploy
```
